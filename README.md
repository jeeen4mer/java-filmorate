# 🎬 java-filmorate

Бэкенд для сервиса, где пользователи могут делиться мнениями о фильмах. В приложении можно ставить лайки, добавлять других пользователей в друзья и получать рекомендации на основе оценок друзей. Также есть возможность выводить список самых популярных фильмов. В основе проекта лежит REST API, данные хранятся в базе H2, а логика реализована на Java с использованием Spring Boot.

---

## ✨ Функциональность

- CRUD-операции для фильмов и пользователей
- Добавление и удаление лайков к фильмам
- Добавление в друзья и подтверждение дружбы
- Вывод списка общих друзей
- Рекомендации фильмов на основе лайков друзей
- Вывод топ-N популярных фильмов

---
